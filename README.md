# Voyagers - Smart Personalized Travel Platform

## 📌 Overview

Voyagers is a full-stack travel planning platform.

The goal of this project was to design and build a connected,
personalized travel experience that goes beyond simple booking systems.
Voyagers helps users plan smarter, travel more comfortably, and connect
meaningfully during their journeys.

## 🚀 Tech Stack

-   **Frontend:** React
-   **Backend:** FastAPI
-   **Database:** MySQL
-   **Version Control:** GitHub
-   **Development Tools:** Visual Studio Code
-   **Design & Planning:** Miro, draw.io

## ✨ Key Features

-   Smart travel companion matching
-   Local guide booking
-   Real-time language translation
-   Currency conversion
-   Personalized restaurant & attraction recommendations
-   Custom packing list generation
-   Optional travel insurance selection

## 🧠 Software Engineering Practices Applied

During development, we focused heavily on structured software
engineering principles:

-   Requirements gathering and analysis
-   Use case design to capture user interactions
-   Domain modeling to define system entities and relationships
-   Modular architecture for scalability
-   Agile development methodology with iterative feature releases

## 🏗️ System Design Approach

The system was designed using:

-   Modular backend architecture
-   RESTful API design
-   Clear separation of concerns between frontend and backend
-   Scalable database schema design
